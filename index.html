PROJECT INFO

This project is a modern, browser-based first-person aim trainer built with Three.js. Players can expect immersive movement (running, walking, crouching, jumping), realistic weapon handling (pistol, reloading, muzzle flash, ammo management), and dynamic UI elements (health/stamina bars, inventory sidebar, gun info, reload/stamina messages). The game features sound effects, a controls guide modal, and a sleek interface.
